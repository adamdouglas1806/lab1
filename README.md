# F27SA Software Development 1 Lab 1
In this week's lab, we want to build a small application based on last week's lectures to practice some basic programming skills.
We want to create a microwave app that guides users in setting popcorn cooking time

## Program Description
Our application first greets the user and asks how many packs of popcorn they want to make. Then, based on the user input, the application should guide the user about the microwave time setting. 
### Required Specification:
1.	To complete the popping, each pack of popcorn needs 3 minutes and 25 seconds.
2.	The program should ask the user about their full name to display a custom message. 
3.	The program should ask the user how many popcorn packs they want to pop. 
4.	The program should calculate the number of seconds it needs to pop the packs.

### Optional Specification:
5.	The program should calculate the number of minutes and seconds to pop the packs.


Sample Output:

```
Welcome to IPopcorn
*******************
Please enter your name: Kayvan
Hello Kayvan, how many Popcorn packs do you have for today? 10
Please set the time to 2050 Seconds
Please set the time to 34 min and 10 sec.

```
